## 数据与运行说明

- `./scripts/build-app.sh` → `work/Copy.app`；`./scripts/build-app.sh --ui-test` → 隔离 UI 测试应用。脚本均不自动启动。运行正式构建仍须用户主动同意采集。
- 正常默认资料库为 `~/Library/Application Support/Copy`。恢复时可选新目录，下次启动切换；旧库保留。恢复切换的完整 UI 仍待验证，不能只凭数据层测试声明通过。
- 删除/清理用 SQLite 写事务协调资产引用与其他进程；普通分钟维护不再每次扫描全部附件，明确清空/删除后回收、闲置孤儿扫描最多每小时一次；保留期变更先原子提交设置与清理范围，资产回收交给下一次分钟维护，避免事务回滚后丢附件。采集预算仍检查管理目录容量，大库采集/空闲开销尚待测量。
- 导出不加密，包含正文和附件。`missingAssets` / `missingFileReferences` 明确缺项，缺失引用不称作完整备份；书签不导出。目录不自动递归快照。
- MCP 默认关闭，只监听 `127.0.0.1:53647`，协议固定 2025-11-25。客户端令牌仅显示一次，保存到本设备 Keychain；可申请写入的客户端仍需在 Copy 内批准每个具体变更。
- `work/` 不提交 Git。保留小型合成 UI 库、两种开发应用、最新验证日志和增量构建缓存供继续开发；不删除真实资料库、用户文件或其他任务缓存。
