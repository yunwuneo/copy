# Copy 产品实施建议

日期：2026-10-15。状态：调研后的建议，尚未确认为需求基线；本轮未开始应用实现。

事实依据见 [Paste 功能调研](../research/paste-feature-research.md)。下文的阶段、设计、测试要求均为本项目建议，不代表 Paste 的内部实现。

## 1. 目标与定位

目标是让用户在 Mac 上稳定收集与复用内容，并在 iPhone/iPad 上通过系统允许的入口收集、查找和使用同一份资料。可衡量的成功是日常流程可替换，而不只是菜单中出现同名功能。

建议独立设计交互和视觉；先保证内容不丢失、搜索可靠、回贴正确、数据可以迁移。AI 和协作应进入完整路线图，但不阻塞基础能力交付。

## 2. 分阶段推进

| 阶段 | 建议交付 | 对应调研功能 | 退出条件 |
|---|---|---|---|
| P0 产品与数据契约 | 确定最低系统、内容格式、文件策略、删除/去重语义、同步与隐私模型；建立原型测试清单 | 全部，优先解决报告第 7 节未知项 | 规则明确且可以据此编写验收用例 |
| P1 Mac 本地日用闭环 | 采集、存储、召回、搜索、收藏、直接/纯文本回贴、排除与暂停、保留期 | F01、F04–F14、F18–F22、F26–F27、F32–F35、F50–F52 | 重启不丢；权限拒绝可用；多应用回贴通过；过期不删收藏 |
| P2 移动与跨端 | iPhone/iPad 主应用、分享/操作/键盘扩展、iCloud、同步状态与恢复 | F02–F03、F39–F49 | 两台真实设备闭环；离线重连、附件失败及删除传播有证据 |
| P3 高效使用 | Stack、批量输出、图片文件输出、OCR、编辑、系统搜索/组件、Shortcuts | F15–F17、F23–F24、F28–F31、F54 | 顺序与格式正确；中文 OCR 和大历史可检索；扩展内存受控 |
| P4 协作与 AI | 共享板、Writing Tools、智能推荐、MCP 授权和读写工具 | F25、F36–F38、F55–F60 | 撤权有效、写操作明确授权、失败不误报成功 |
| P5 发布准备 | 无障碍、本地化、迁移导出、存储管理、分发与可选商业化 | F53、F61–F63，以及本项目改进项 | 真机兼容与升级迁移通过，发布边界明确 |

P2/P3 先后可按用户重心调整。隐私、无障碍和存储控制从 P1 起持续实施，P5 是最终验收，不是首次考虑这些问题。

## 3. 数据与存储设计方向

- 内容与呈现分离：保留原始类型表示、可检索文本、来源与时间；缩略图/OCR 属于可重建派生数据。
- 明确文件语义：原路径引用、受控快照、可跨端附件分别定义；不把失效路径显示为可正常粘贴的文件。
- 去重需区分“相同内容”“同一条目的再次复制”和“同一同步事件”，不能仅按显示字符串合并。
- 历史期限、容量预算、收藏保护和人工删除分别处理；先让用户看见预计清理范围，再执行破坏性清理。
- 同步应定义对象版本、删除标记、重试与冲突规则；离线设备重连后不能复活已删除内容。
- 为键盘扩展提供轻量数据和缩略图访问，避免为查看几个条目加载完整历史。
- 提供可导出的内容和元数据方案；接入 Paste 导入前先验证合法可用的导出途径和数据格式，不直接修改其数据库。

这些是待设计的契约，不锁定数据库或同步框架。Swift/SwiftUI 与必要的原生平台集成是候选方向；选型需在 P0 结合系统要求和扩展约束决定。

## 4. 核心验收场景

| ID | 场景 | 验收重点 |
|---|---|---|
| A01 | 连续复制文本、链接、图片、文件并重启 | 原内容、格式、来源、顺序与持久化 |
| A02 | 相同文本从不同应用复制/两端同步 | 按既定去重规则处理，无回环与无限新增 |
| A03 | 拒绝或撤销 Mac 辅助功能权限 | 仍能查历史并复制回剪贴板；清楚提示手动粘贴 |
| A04 | 排除应用、临时/敏感标记、暂停 | 在入库前过滤；日志不记录实际敏感内容 |
| A05 | 富文本、多选、纯文本、Stack | 格式转换、顺序、分隔符、目标焦点和失败处理 |
| A06 | 收缩保留期/清空历史 | 收藏不误删；有明确确认；结果与磁盘回收符合契约 |
| A07 | iPhone 后台连续复制再回应用 | 正确说明仅取得当前项；不伪造缺失历史 |
| A08 | 分享/键盘扩展拒权、终止、内存压力 | 降级可理解，写入原子化，不产生半条记录 |
| A09 | 两台真机断网、修改、删除、恢复网络 | 无丢失/重复/删除回流，冲突结果可解释 |
| A10 | 大附件未下载、失效原文件、磁盘不足 | 原条目不被空内容覆盖；可重试且不会误报完成 |
| A11 | 中文图片 OCR 与大量历史 | 可找到正确结果；测量延迟、内存、索引恢复；阈值在 P0 定义 |
| A12 | 共享只读、写入、撤权、离线恢复 | 权限生效；不宣称能收回已导出的副本 |
| A13 | MCP 未授权、授权、撤销、写请求重试 | 读写范围明确，令牌不泄漏，变更不重复执行 |
| A14 | AI 不可用、屏幕访问拒绝、排除应用 | 核心剪贴板仍可用；临时屏幕信息生命周期明确 |
| A15 | VoiceOver、大字、深色、键盘导航 | 焦点顺序、可读标签、非颜色提示与可操作性 |
| A16 | 升级、迁移、导入导出、恢复 | 数据版本可迁移，失败可恢复；导出结果可独立读取 |

测试数据采用合成样本，不默认采集真实密码、聊天或业务资料。结构检查、单测、模拟器、真实设备、真实目标应用分别报告，不互相替代。

## 5. 产品规格阶段需要确定的事项

1. 优先个人自用还是商业发布，是否包含家庭/团队授权。
2. 最低 macOS/iOS/iPadOS，以及是否保留 Intel 支持；不直接照抄竞品的最新门槛。
3. 第一版是否必须同时交付两端；建议先 Mac 日用闭环，再验证同步和移动扩展。
4. 默认历史期限与容量预算；永久收藏超出预算时的用户选择。
5. 同步是否采用个人 iCloud，是否需要其他后端；不能默认引入服务器成本。
6. 共享与 MCP 是否属于第一版；建议后续阶段提供，默认关闭并单独授权。
7. 是否需要迁移现有 Paste 历史；如需，先验证读取/导出方式，再设计导入器。

当前完成物是可追溯的调研与仓库基础，不代表以上产品选择已获确认。
