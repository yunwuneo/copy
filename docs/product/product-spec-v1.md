# Copy 完整产品功能规格 v1

日期：2026-10-15。产品暂用名：Copy。状态：可用于实施拆解的规格；功能尚未实现或实测。

## 1. 已确定的目标与范围

用户确定的方向：**完整替代 Paste，功能对标，UI 独立设计；先完成 macOS 完整产品，再开发 iOS/iPadOS。只做完整版，不设置日用版、MVP、精简版或功能删减版发布目标。**

内部可以按依赖拆分任务、制作验证构建，但这些都不是独立产品版本，也不能以基础功能通过代替完整版完成。macOS 中适用的全部功能验收完成后，才进入移动应用实现；依赖移动端的跨端验收在移动阶段完成。Mac 阶段先用两台 Mac 验证同步与两账号协作。

本文定义 Copy 应当如何工作，不声称这是 Paste 的内部设计。竞品事实以 [调研报告](../research/paste-feature-research.md) 的 F01–F63 为依据；映射及具体测试见 [功能对照与验收](acceptance-and-traceability.md)，执行顺序见 [实施计划](implementation-plan-v1.md)。

### 1.1 完整替代的定义

- 覆盖采集、历史、检索、预览编辑、粘贴、队列、收藏、同步、共享、系统扩展、自动化、隐私、AI、MCP、无障碍和数据迁移。
- 每项有功能实现、异常处理与相应层级证据；系统限制必须明确展示，不能用虚假成功或隐藏入口掩盖缺失。
- “完整”指下文列明的平台适用能力，不要求 iOS 实现系统禁止的全局后台监听，也不要求在不支持 Apple Intelligence 的设备运行该模型。
- Paste 的订阅价格、Setapp 合作和售卖渠道属于商业模式，不照搬。完整产品没有按套餐切割功能；商业管理作为明确的可选范围 R24，不影响个人与共享协作功能完整性。不得宣传“复刻了 Paste 全部商业渠道”。
- 屏幕捕获防护、专有内容格式、竞品导入器等无法直接保证的部分必须保留差距记录。基础能力可用不意味着这些差距已关闭。

### 1.2 设计基线（本项目决策，不是用户另行确认的事实）

这些默认值使实施可启动；如技术验证推翻，应记录原因、替代方案和验收影响，再修改规格，不默默换方向。

| 项目 | v1 基线 |
|---|---|
| 系统 | macOS 14+；后续 iOS/iPadOS 18+。使用新 API 时按可用性隔离；系统门槛在 T01 用已安装 SDK 验证 |
| Mac 芯片 | 基本功能以 Apple Silicon 与 Intel 为目标；未取得 Intel 真机证据前只能标“未验证”，不能宣称全兼容 |
| 原生实现 | Swift，共享领域层；SwiftUI 为界面基础，桌面窗口/输入及扩展使用必要的 AppKit/UIKit 桥接 |
| 数据 | 本地优先；SQLite 元数据/索引与独立附件存储；可选个人 iCloud/CloudKit，无自建剪贴板内容服务器 |
| 发布 | Mac 优先完成可签名、公证的直接分发构建；Mac App Store 兼容性验证保留。iOS 经 TestFlight/商店交付；实际上传、发布单独执行 |
| AI | 写作工具与智能推荐分别开启；推荐只用可用的本机模型，不自动切换云模型或下载第三方大模型 |
| 采集默认 | 首次说明后开始；敏感/临时标记过滤开；登录启动关；同步、MCP、智能推荐、外部链接自动预览关 |
| 历史/容量 | 历史 30 天；Mac 管理数据预算 512 MiB、移动 256 MiB；派生缓存预算分别 64/32 MiB；可调整 |
| 语言 | 简体中文、英文为交付语言；文案、时间、排序和无障碍标签可本地化 |
| 商业化 | 完整功能内部许可，不预设价格/订阅；不为续费、激活搭建服务器 |

容量数字是工程起始预算，并非系统限制或实测结论；超限行为见 R13。iOS 的更低系统门槛是本产品选择，不是对 Paste 兼容性的描述。

## 2. 用户任务与独立 UI

### 2.1 核心任务

| 用户任务 | 完成标准 |
|---|---|
| 找回刚才或很久前复制的资料 | 按关键词、图片文字、应用、时间、设备或收藏集合找到正确条目 |
| 跨应用重复输入 | 无需反复切换源应用；支持原格式、纯文本、批量和逐项粘贴 |
| 留存常用素材 | 收藏不会因历史过期丢失；可编辑、命名、排序、分享 |
| 换设备继续工作 | 已保存数据可同步；未下载、冲突和断网状态可解释 |
| 控制敏感内容 | 能排除应用、暂停、删除、关闭同步和撤销 AI 访问 |
| 长期使用与退出产品 | 存储可控，数据可导出，升级可恢复，不因软件授权状态丢失资料 |

### 2.2 信息架构与交互约束

**Mac 快捷面板**：紧凑竖向结果列表，上方搜索框，下方键盘动作提示，可选右侧预览。默认显示最近历史，支持收藏集合切换、筛选及队列入口；宽度/高度可调。出现在当前工作显示器范围内；不跨屏、不强制改变目标应用焦点。关闭面板后回到原应用。

**Mac 资料库窗口**：左侧“历史、收藏集合、共享集合、待处理”，中间列表，右侧详情。用于批量整理、编辑、导入导出及处理冲突。设置分为采集、粘贴、存储、同步、隐私、快捷键、智能与连接、关于。

**iPhone**：历史、收藏、搜索三个主要入口，设置从导航菜单进入；详情与编辑为独立页面。分享面板以保存目的地为核心；键盘以快速复用为核心。

**iPad**：同一资料库的自适应侧栏/列表/详情，可分屏和拖放。窄窗口退化为单列，不压缩成无法触控的桌面布局。

**设计约束**：不使用 Paste 的品牌、图标、截图、配色方案或底部横向卡片布局。使用系统字体、语义颜色、8 pt 间距基准；颜色不承担唯一含义。密度可选，正文可选择复制。系统原生权限和分享界面不为“独立设计”而重画。

### 2.3 全局状态与反馈

- 搜索中、无历史、无匹配、加载中、附件未下载、读取权限不足、磁盘不足、同步失败均有独立状态。
- 空历史解释开始采集的方法；无搜索结果提供清除筛选，不引导用户重装。
- 状态提示不包含剪贴板正文；后台同步失败不抢焦点。用户触发的失败显示原因及可行下一步。
- 显示“已保存到本机”“等待同步”“已写入系统剪贴板”“已发送粘贴命令”等准确状态；不能把发送按键当作目标应用已接受。
- 全键盘可操作：上下移动、Tab 切换区域、Return 执行动作、Escape 逐层退出；输入法组合输入期间不误执行。

## 3. 产品功能契约

编号 R01–R24 是 Copy 的需求模块，F 编号保留给竞品调研。验收 Q 编号见验收文档。

### R01 — 首次设置、常驻与权限（Mac，后续移动适配）

首次启动说明“保存何种数据、保留多久、如何暂停”，用户开始后才采集。允许跳过同步、登录启动、辅助功能、屏幕访问和键盘授权，主功能不被整个锁住。Mac 关闭窗口继续驻留，显式退出停止；休眠/锁屏期间暂停读取，解锁后只读取当前剪贴板，不能假称补齐期间全部事件。

菜单栏有打开面板、资料库、暂停状态、设置、退出。登录启动由用户开关控制，显示系统实际状态；失败不自动反复注册。权限按首次使用请求，撤销时重新检测。移动端按读取、分享、键盘分别解释，拒绝时保留已有数据浏览。

验收：Q01、Q02、Q03。

### R02 — 采集、来源与重复内容（Mac）

采集顺序：检测系统剪贴板变化 → 暂停/锁屏检查 → 来源排除 → 临时/敏感类型过滤 → 支持类型与容量判定 → 持久化 → 异步索引/预览 → 按用户设置排队同步。过滤必须发生在内容写盘、OCR、索引和同步之前。

记录实际观测时间、来源设备和尽力识别的源应用；不能确定时显示“来源未知”，不能把当前前台应用当作可靠来源保证。Copy 自己写回的剪贴板通过进程内写入标记/变更编号防回环；标记不是安全凭证。通用剪贴板输入以实际接收内容处理，不伪造远端来源。

同一资料库内，完整类型表示一致且有效的条目复用内容实体，追加轻量复制事件，列表按最后捕获时间前移；不同富文本、文件版本、人工编辑内容不只按纯文本去重。跨设备相同实体的同步不是一次新复制；有删除标记的条目不能由旧同步事件复活，用户再次真实复制创建新实体。

未知剪贴板类型不运行内容、不触发脚本；有安全纯文本表示时可降级并提示。轮询可能错过比检测频率更快的系统覆盖，必须通过连续复制测试测量边界，不宣称无条件零丢失。

验收：Q04、Q05、Q06、Q07。

### R03 — 内容格式与附件

| 类型 | 保存与展示 | 输出/边界 |
|---|---|---|
| 纯文本/代码 | 保留原始 Unicode、换行、空格，代码不执行 | 原文本；不擅自格式化 |
| 富文本 | 保存可用的 RTF/HTML/纯文本多表示；显示安全预览 | 尽量还原原格式；目标不支持时提供纯文本 |
| URL | 原 URL、可改标题；远端元数据获取默认关 | 打开前校验协议；http/https 外确认交给系统处理 |
| 图片 | 原始受支持图片数据、尺寸、缩略图；动画不默认转为静态原件 | 图像或文件输出；仅预览缩略图可取首帧并标识动画 |
| 颜色 | 独立六位 HEX 识别规则沿用调研 F05；原文本始终保留 | HEX 文本及色块；颜色选择器修改生成新修订 |
| 文件/多文件/PDF | 默认保留文件引用与可用元信息；有读取权限且满足下列限额的普通文件自动创建受控快照 | 文件 URL 或已下载快照；PDF 预览不等于全文 OCR |
| 专有对象 | 可安全保存的原始表示由适配器处理 | 不支持则明确列差距，不把显示图片当作可编辑对象还原 |

自动受控快照上限：单文件 20 MiB、单次多文件总计 50 MiB；超过上限只保留本地引用及状态，不自动读取/复制整个目录。用户可主动“保存副本”并看到大小预算；目录默认不递归快照。文本单条自动保存上限 5 MiB、图片原始载荷 20 MiB；超过阈值显示跳过原因而非静默截断。手动导入遵守总预算并可调整单次限额。

文件引用不上传为可跨设备使用的附件。跨设备条目可显示“仅在来源设备可用”；用户保存副本成功后再提供附件同步。原文件消失不删除历史，提示重新定位/使用已有副本。附件下载失败保留旧内容和元数据。

验收：Q08、Q09、Q10、Q11。

### R04 — 历史、详情和选择

历史默认按最后捕获时间倒序，时间相同按稳定 ID 排序；展示类型、内容摘要、来源、时间、收藏/同步状态。支持单选、范围选择、多选、全选；列表分页，默认每页 50 项，不一次载入全部附件。同步插入时保留当前滚动位置和选中对象，避免粘贴目标随列表重排改变。

资料库提供复制事件详情；列表默认聚合重复内容。选择使用 itemID，不依赖行号。删除或撤权导致选中项不存在时清除选择并解释，不自动选择下一条执行。

验收：Q12、Q13。

### R05 — 搜索、过滤、OCR 与定位

搜索覆盖有效历史和收藏，明确展示范围；可选当前集合或多个集合。关键词匹配标题、正文、文件名、可用 URL 元信息及图片 OCR；支持类型、应用、设备、日期区间、集合过滤。同一维度多值 OR，跨维度 AND；日期按用户时区展示、转换为 UTC 半开区间查询。中文、英文、大小写与组合字符测试必须覆盖；不隐式把用户输入当正则表达式。

默认相关性优先、同分按时间，用户可切换时间排序。结果标出匹配字段/OCR 区域；“定位到历史/集合”退出搜索并定位原对象。已过期仅存收藏的项只定位到收藏；不存在的项不显示空详情。

OCR 默认本机后台处理支持图片，限制并发为 1，先缩略分析后按需精读。识别失败仍可使用原图，提供重试；更换图片修订后旧 OCR 失效。索引是可重建派生数据，版本落后自动补建并显示进度。v1 不承诺任意扫描 PDF 全文索引。

验收：Q14、Q15、Q16、Q17。

### R06 — 快速调用、直接粘贴与纯文本（Mac）

默认 ⇧⌘V 唤起/关闭；面板出现前记录目标应用与焦点上下文。上下键选择，Return 输出；⌘1–9 作用于当前可见结果快照的前九项，按住修饰键显示编号。新数据到达不改变本次已展示编号的对象绑定。快捷键冲突须提示并允许修改/清空/恢复默认。

直接回贴：检查权限和目标 → 准备完整内容 → 写系统剪贴板 → 恢复原应用 → 发送一次粘贴。目标已退出、焦点变更或权限不足时只复制并提示手动操作；不盲发到其他应用。默认保留格式，⇧Return 或设置选纯文本；转换只影响此次输出，不改数据库原件。

有可用 URL/文件时支持系统打开，危险或未知协议需要用户明确动作。默认不恢复输出前的剪贴板，避免异步目标还未读取就被覆盖。输出操作使用冻结内容版本，过程中编辑不会混入一半新内容。

验收：Q18、Q19、Q20。

### R07 — 多项输出与拖放

批量输出默认使用当前列表展示顺序，执行前可查看/调整；不以不可见的点击顺序拼接。纯文本默认换行分隔，可选空格、空行或自定义分隔符；链接按 URL 输出。多个富文本按段落组合，保留支持的格式；混合类型无法合成时让用户改为文件输出或队列，不悄悄丢项。

文件和图片可输出为文件集合，按目标接受的系统类型提供；拖入与拖出使用明确数据提供器。临时输出文件计入缓存，传输完成后释放；无法得知接收方完成时保留到会话结束或 24 小时上限，清理不得破坏仍被本进程使用的文件。超过空间阈值先失败，不生成无限副本。

验收：Q21、Q22。

### R08 — 顺序粘贴队列（Mac）

默认 ⇧⌘C 开启收集，复制项追加到临时队列；可从历史/收藏多选入队、调整顺序、反向、删除单项和退出。队列是会话工作区，不会移动或删除历史原件。

用户明确启用队列输出后，⌘V 请求输出队首；处理热键重入及 Copy 自己发出的按键，防止重复消费。每项状态为 ready → preparing → dispatched；仅在已完成剪贴板写入并成功发送命令后前进。这个状态叫“已发送”，不保证目标插入成功。失败留在队首；结果不确定暂停，提供“重试本项/视为已用”，不得自动重发。支持撤回队列消费指针，但不尝试撤销外部应用内容。

退出队列恢复正常 ⌘V；应用重启后可提示恢复队列但保持暂停，绝不自动继续向外粘贴。已删除、无权限或未下载的队列引用须重新验证。

验收：Q23、Q24。

### R09 — 预览、创建与编辑

空格或详情打开预览；文本可选择、富文本安全渲染、图片缩放、PDF 分页、链接可选择打开内置浏览视图。未主动打开链接前不加载远端资源；浏览视图使用隔离会话，不复用浏览器登录数据。预览不执行脚本附件或启动下载。

支持新建文本/链接、改名、文本与受支持富文本编辑、图片旋转、OCR 文字提取、颜色选择、系统分享；保存生成修订，取消无变化。未支持的格式编辑另存为新条目并说明，不悄悄丢原始表示。并发修改检测基于修订号；发生冲突允许保留双方。

支持系统写作工具时提供其原生入口，接受结果前展示预览；它与 R17 推荐分开开关。Mac 通过可用的 Continuity Camera 扫描入口接收 iPhone 文档，移动端提供原生扫描入口；取消、设备不可用、扫描权限拒绝不创建空条目。扫描在 Mac 阶段需要兼容 iPhone 作为系统外设验证，不要求提前开发 Copy iOS。

验收：Q25、Q26、Q27、Q28。

### R10 — 收藏集合与排序

集合可创建、命名、配色、排序，项可批量加入、移动、取消收藏和手动排序。为控制复杂度，一个私有 item 在个人资料库最多属于一个个人集合；历史可同时引用该 item。新建空名不允许，重名允许但界面展示位置区分；颜色配合文本或符号标识。

收藏保护内容不被历史过期或清空删除。取消收藏时若历史资格已过期，提示将失去保留位置，并按 R11 删除策略处理。删除集合默认仅解除集合归属、保留仍有效的历史项；对“仅收藏保留”的项目列明数量，允许先导出、转移或明确删除。用户也可选择删除集合及全部内容，必须明确影响范围。此删除语义是 Copy 的独立设计。

跨个人/共享集合移动采用“复制到目标并可选移除原件”，身份与权限隔离；不得意外公开个人历史。

验收：Q29、Q30。

### R11 — 删除、保留期与撤销

历史保留选项 1 天/7 天/30 天/365 天/永久，按 item 最后真实捕获时间计算；收藏保护、共享内容生命周期单独处理。同步资料库使用同一历史策略，策略变更同步；设备缓存预算仍各自独立。移动端可查看并修改本产品的资料库保留策略，不受竞品无入口限制。

保留期以 UTC 计算；系统时区改变不改变实际过期时间。检测到时钟异常跳变时暂停破坏性过期清理并提示校正，不因一次时间跳变批量删除历史；测试用可注入时钟验证。云端同步到达不重置真实捕获时间。

“移出历史”只移除历史资格，仍被收藏的内容保留；“删除此内容”覆盖该资料库内历史/收藏引用并显示影响；“清空历史”不删收藏；“清空个人资料库”与“停止共享/删除共享集合”独立。任何批量破坏性操作显示条数、附件大小、同步影响和不可撤销说明。

单次人工删除提供 10 秒撤销：立即从 UI 隐藏但延迟提交持久删除，崩溃重启后按事务日志完成或撤回，不重现已确认彻底删除的项。用户可选择立即彻底删除。过期、清空、共享撤销不提供虚假的通用撤销。派生索引及缓存随删除失效，附件在无引用且事务已提交后回收；云端离线时显示删除待同步。

删除标记不含正文；同步旧写入不能覆盖删除。用户再次主动复制属于新记录。无回收站长期保存敏感原文；导出备份和外部副本不随应用删除自动消失。

验收：Q31、Q32、Q33。

### R12 — 隐私规则与演示保护

Mac 排除应用按 bundle identifier 管理，规则更改只影响未来采集；支持从来源菜单快速排除。默认跳过机密/临时标记；不承诺识别所有密码或任意个人信息。暂停可选 5 分钟/30 分钟/1 小时/直到恢复；锁屏及用户退出优先于定时恢复。被过滤的正文不进入日志或统计。

提供手动“演示保护”：遮挡列表正文、缩略图、标题、搜索内容和通知预览；开启时禁用屏幕上下文推荐，用户可暂时揭示单项并得到明确提醒。自动识别录屏后遮挡仅在可验证的系统范围启用。若声称窗口不进入特定捕获链路，必须取得对应 OS/录屏程序证据。

**不能用旧的 `NSWindow.SharingType.none` 实现就宣称完全防录屏。** Apple 当前文档称其为系统不再使用的旧常量；本规格要求实测，无法保障时展示保护范围并保留 F53 差距。参见文末技术来源 E01。

默认不接入第三方使用分析；诊断日志仅状态、错误码、耗时和随机对象 ID，默认保留 7 天且不超过 5 MiB。导出诊断必须可预览，屏蔽正文、文件绝对路径、URL 查询串和凭据。

验收：Q07、Q34、Q35、Q36。

### R13 — 容量管理、备份与迁移

展示数据库/索引、内容附件、可重建缓存、临时文件、待下载数据各自用量。预算包括应用管理的数据，不修改用户原文件。先清理无引用且可重建缓存，再执行已启用的保留策略；仍不足时停止新大载荷写入，显示“未保存：空间不足”，不静默删除收藏。

Mac 可用磁盘低于 1 GiB、移动低于 500 MiB 时停止新附件快照/下载；文本小写入还需检查事务安全余量，不把阈值当作一定可写。附件下载先查预算；远端收藏的缓存可卸载但须确认云端完整副本存在。唯一未同步副本不得作为缓存淘汰。

提供版本化导出包：manifest.json + 内容文件 + SHA-256 清单；支持选择范围与“含附件/仅元数据”。明示未下载附件和引用文件未包含的数量；完整备份只能在缺项为零时标记。v1 导出包不声称加密；导出前提醒内容可读，由用户选择存储位置。

导入先校验版本、大小、哈希、路径、压缩解包上限和类型，再预览数量/冲突，事务写入；禁止路径穿越及执行内容。默认导入为新来源，不覆盖现有内容；同一导入任务重试幂等。Paste 导入适配器先验证可用格式，不直接修改其数据库、不扫描真实历史；没有可靠格式时提供通用导入并将专用迁移标为受阻。

升级前检查空间并仅保留一个必要迁移恢复点；迁移失败保持旧数据可读。恢复备份创建新资料库身份并默认关闭同步，避免把旧数据重新推回当前云端造成删除复活。

验收：Q37、Q38、Q39、Q40。

### R14 — 个人同步与设备管理

同步默认关闭；首次开启说明内容范围、附件预算、账号和上传影响。所有个人历史/集合进入个人 CloudKit 数据库；本地引用文件仅传可用元数据，不上传沙箱书签或绝对路径。凭据、排除应用、窗口位置、权限与 MCP 配置不跨设备同步。

显示关闭、等待账号、初始同步、正常、离线待同步、配额不足、重试、冲突、需操作状态；有最后成功时间、待上传/下载数和手动重试。系统后台调度不保证时延；主应用活跃时可主动请求同步。CKSyncEngine 的调度不确定且状态需落盘，不能以本地写入返回代表云端完成（E02）。

每条变更带稳定 ID、资料库身份、基准修订、操作 ID。冲突策略：删除优先于旧编辑；正文冲突保留两份可恢复修订让用户选择；不同字段可合并；顺序冲突确定性排序并提示。不得仅靠设备墙钟最后写入胜出。

关闭个人同步只停止个人同步并保留本地数据，不默认删除云端或结束共享；修改离线个人副本后重开须先拉取云端删除与版本并调和，不能把全量本地当新上传。账号切换隔离资料库，默认隐藏旧账号数据，需明确保留为独立本地库或删除；不将 A 账号内容自动上传至 B。

云端重置必须作为独立危险操作列出影响与恢复来源，不能在普通“修复同步”里执行。长期离线设备或同步令牌失效先全量对账；轻量墓碑不能随意按固定天数删除。压缩墓碑须使用资料库 generation 更新与旧客户端全量重建协议。

验收：Q41、Q42、Q43、Q44、Q45。

### R15 — 共享集合与协作

使用独立共享域；所有者可邀请指定用户或显式启用链接加入，默认指定用户且只读。支持 owner/editor/viewer，参与者列表、撤销、退出和停止共享；仅 owner 调整成员和权限。共享入口先展示集合全部内容与附件是否准备齐全，不分享个人历史或未选择集合。

editor 可增删改共享条目，viewer 只能读取/复制；服务端和本地双重校验。共享条目与个人原件为独立 ID，复制到个人库是显式导出行为。共享编辑需有已确认的访问权；离线编辑可保存为本地草稿，重连重新授权后提交，撤权后拒绝写入并允许导出用户自己的未提交草稿。

停止共享/被移除后，在线确认撤权即隐藏并移除本机受控缓存；离线无法立刻获知远端撤权，不承诺即时远程擦除，已被复制导出的数据也不能收回。个人同步与共享开关分开；关闭共享连接须说明保留的服务端共享及本机缓存，不隐式停止所有者共享。

验收：Q46、Q47、Q48。

### R16 — 系统搜索、Shortcuts 与组件

Shortcuts 提供添加文本/链接、读取最近项、按索引取集合项、搜索、打开指定集合；参数有范围、类型、数量和输出形式，默认最多 20 条，空结果与无权限是不同结果。新增/写入动作经同一领域服务和隐私检查；不自动粘贴到外部应用。

系统搜索默认关闭，用户可仅索引选定收藏集合；开启后删除/撤权要同步移除系统索引。深链只包含不可猜测对象 ID 或导航参数，不包含正文/令牌；打开时重新校验资料库和权限。

移动组件提供小/中号集合入口，可选择显示最近项摘要；默认仅显示集合名，不在锁屏泄露正文。刷新遵循系统调度，无后台采集承诺；点击进入指定页面。Mac 自动化先完成，移动系统入口在移动阶段实现。

验收：Q49、Q50。

### R17 — 本机智能推荐与写作能力

智能推荐为独立可选功能。点击开启并说明访问范围后，请求必要的屏幕访问；仅面板打开且用户使用推荐视图时获取当前目标窗口的最小上下文。排除应用、演示保护、锁屏和无法确认安全的字段状态均不得读取；无法可靠识别密码区域时不抓取该上下文，可退化为基于用户输入查询的推荐。

本地检索先选候选，再由可用本机模型排序，输出仅引用存在且有权读取的 itemID；不根据屏幕文字执行工具、不修改原件、不凭空创建“历史”。面板关闭取消请求并释放屏幕缓冲，不存盘、不上传、不进日志。列表原排序保留，推荐另视图展示；可撤销权限/关闭功能。

macOS 26+ 且本机模型可用时提供智能路径；设备、地区、语言、模型未就绪分别提示。5 秒未返回先展示普通搜索，晚返回不改变已选条目。系统写作工具由 R09 提供原生行为，不把其所有可选扩展统称为本地推理。本产品不自动接入云端替代模型。模型可用性参照 E03。

验收：Q28、Q51、Q52。

### R18 — MCP 与 AI 客户端访问（Mac）

默认关闭，仅监听本机回环地址；每个客户端有独立令牌，存于 Keychain，界面可查看权限、最近连接及撤销。校验请求 Origin/Host 与凭据，拒绝非回环访问和未授权浏览器请求；不提供端口转发或公网入口。传输版本在 T17 依当前 MCP 官方协议锁定，不能猜测兼容格式。

权限拆分：search.metadata、items.read、items.create、items.update、collections.read、collections.write。默认授权只读且限定选定集合；整个个人历史需额外明确选择。搜索摘要也属于数据披露，不绕过集合范围；共享内容默认不向 AI 开放，需独立选择且现有共享角色允许。

拟定工具契约：

| 工具 | 输入核心字段 | 输出与规则 |
|---|---|---|
| search_items | query、filters、cursor、limit | 有权限的元数据；上限 50；不返回未获正文权限的数据 |
| get_item | itemID、representation | 指定表示；附件使用受限读取，不泄露任意本地路径 |
| list_collections | cursor、limit | 仅已授权集合 |
| create_item | operationID、destination、content | 同意写入后返回 itemID、revision、状态 |
| update_item | operationID、itemID、baseRevision、patch | 版本冲突失败，不盲覆盖 |
| create_collection / move_item | operationID、目标与基准版本 | 权限校验、变更摘要和审批绑定 |
| update_collection / delete_item / delete_collection | operationID、对象 ID、baseRevision、影响范围 | 单对象或明确有界的变更，删除展示收藏/历史影响；不允许通配全库删除 |
| get_operation | operationID | pending/committed/rejected/failed/unknown，供对账 |

所有写操作先形成应用内可审阅变更，用户确认后执行；审批绑定客户端、工具、参数摘要/哈希、资料库范围和基准版本，有效期 5 分钟，过期或参数变化重审。客户端重试复用 operationID；同 ID 不同参数拒绝，提交结果持久记录。连接断开不等于失败，unknown 先对账，不自动再执行。

v1 不通过 MCP 暴露直接向别的应用粘贴、执行剪贴板脚本、删除全部历史、修改权限或导出任意路径。撤权立即阻止新请求，执行中的操作提交前再检查。界面明确第三方客户端可能将已读数据发送到模型供应商。

验收：Q53、Q54、Q55、Q56。

### R19 — iPhone/iPad 主应用（macOS 验收后）

复用内容、修订、搜索、集合、存储和同步契约；原生导航、预览、编辑、批量选择、分享和扫描。前台读取当前剪贴板按系统许可执行；有拒绝权限时提供明确粘贴按钮，不重复弹窗强求。进入前台只取当前项，不承诺恢复过去覆盖内容。

iPad 仅在系统允许的可见/活跃状态持续检测，失去允许状态立即停止；多窗口使用共享事务层避免重复写。主应用点击条目复制，长按选择更多操作；已复制反馈不代表其他应用已粘贴。无来源应用证据时如实显示未知。

验收：Q57、Q58。

### R20 — 移动 Share / Action 扩展

Share 扩展接收系统提供的文本、URL、图片和文件，可选个人历史、收藏或有写权限的共享集合；Action 扩展一键进入个人历史。来源、类型、限额、附件状态与主应用一致。先写入轻量持久接收箱，再返回已接收；全部内容持久化前不提示已保存。

扩展可取消，系统终止后未提交暂存按任务 ID 回收；重试不会重复新增。接收箱按事务恢复，由主应用完成索引/同步；扩展不等待长时间 OCR 或云端上传。提供只读集合、附件超限、空间不足和系统读取失败的具体提示。

验收：Q59、Q60。

### R21 — 移动键盘

键盘展示最近历史、集合和轻量搜索；必须有切换下一键盘入口。文本通过系统文本代理插入；图片/文件不承诺像文本一样直接插入，提供“复制后在目标应用粘贴”或系统允许的拖放路径，不能用占位字符串假装已发送图片。

先尝试无 Full Access 的只读共享快照与文本复用；写入收藏、采集当前剪贴板或所需能力受限时明确引导主应用/Full Access。拒绝后至少保留切换键盘和可用的只读操作，不把系统禁止说成产品故障。读取共享容器的可用性按目标 OS 验证（E04）；不让键盘直接承担云端同步。

键盘不记录宿主按键历史、不读取多余上下文、不发网络请求、不跑 OCR/模型、不加载原始大图。安全输入/电话输入或禁用第三方键盘的宿主回退系统键盘（E05）；不能保证所有应用可用。共享条目缓存要同步权限状态，离线撤权边界遵守 R15。

验收：Q61、Q62、Q63。

### R22 — 无障碍、本地化与设置一致性

Mac 全键盘完成核心路径、VoiceOver 正确读出类型/标题/操作/状态；不默认朗读整段敏感正文。移动端支持大字体、触控目标、自适应布局、减少动态效果和深色模式。颜色之外提供形状或文本，空状态和错误必须可访问。

设置分为资料库级（历史期限）、设备级（缓存预算/采集/快捷键/隐私）、账号域级（同步/共享）、客户端级（MCP 授权）。界面注明影响范围；改变一台设备的窗口设置不得影响其他设备。简中与英文覆盖首次启动、权限、错误和恢复路径。

验收：Q64、Q65。

### R23 — 分发、升级与诊断

Mac 完整交付包含实际签名/公证验证、启动/退出/登录启动、权限跨升级行为、数据迁移与卸载指引。卸载指引说明应用文件、本地数据、iCloud 和共享分别如何处理，不提供一键误删其他用户资源的清理。版本更新失败保留原应用和资料库；兼容性未验证不静默升级数据格式。

iOS 完整交付包含真机安装、所有扩展签名与 App Group/CloudKit 配置、TestFlight 验证和隐私声明。诊断导出使用 R12 脱敏规则；发布说明列出系统限制和已知差距，不能以测试替身代替系统集成。

个人使用、同步与共享是完整版功能，不因尚未设计收费而删减。预留 entitlement 适配边界，但内部构建全部功能可用；许可证过期也不得删除用户数据或禁止导出。

| ClipItem | itemID、libraryID、kind、title、currentRevision、createdAt、lastCapturedAt、inHistory、collectionID、deletedState |
| ClipRevision | revisionID、parentRevisionIDs、representations、contentDigest、actorDevice、修改原因；支持冲突保留 |
| CaptureEvent | eventID、itemID、deviceID、observedAt、sourceApp（可空）、ingress；不等于内容副本 |
| Representation | typeIdentifier、inline/blob/reference、size、hash、可用状态；多种表示属于一个修订 |
| Asset | assetID、hash、byteSize、localAvailability、remoteAvailability、refCount；数据域内去重，跨账号不共享物理缓存 |
| FileReference | 本机书签/路径授权、设备 ID、显示名；书签与绝对路径永不跨设备同步 |
| Collection | collectionID、libraryID、name、color、orderKey、shareRole；同域 item 最多一个集合 |
| SyncRecord | remoteID、serverChangeTag、pendingOperationID、lastAcknowledgedRevision、generation |
| Tombstone | objectID、libraryID、generation、删除版本、确认状态；无正文 |
| QueueSession | sessionID、冻结修订引用、顺序、游标、paused/dispatched/unknown；不影响历史归属 |
| Operation | operationID、actor、payloadHash、baseRevision、状态、结果引用；重试对账 |
| AccessGrant | clientID、令牌引用、scopes、allowedCollections、expiresAt/revokedAt；不存明文令牌 |
| DerivedIndex | itemID + revisionID + 算法版本；搜索/OCR/缩略图失效与重建 |

本机内容提交、元数据和出站变更日志在同一事务边界内可恢复；附件先临时写、校验，再原子交接，失败不留下指向不存在文件的已完成记录。不同进程写入通过短事务/可恢复接收箱协调；不得以 Swift actor 代替跨进程互斥。iOS 扩展不直接执行数据库 schema 迁移。

数据保存在应用私有目录或受控 App Group，采用平台文件保护与最小文件权限；令牌进入 Keychain。v1 不宣称数据库有独立应用级全盘加密或端到端加密，也不把 iCloud 私有数据库等同于该承诺。锁屏时停止敏感读取和输出；文件保护导致暂不可读时显示等待解锁，不误判为内容已丢失。

删除/撤权必须同时让搜索、系统索引、键盘快照、队列、AI 候选失效；只隐藏主列表不算删除。存储层和服务层负责强制校验，不能只靠按钮禁用。

## 5. 状态、错误与恢复

| 范围 | 状态流 | 失败处理 |
|---|---|---|
| 采集 | observed → filtered 或 persisting → stored → indexing | 空间不足/类型不支持返回未保存；不伪造 stored |
| 附件 | referenceOnly / pendingDownload → available / failed | 显示来源与重试；原有可用副本保留 |
| 输出 | prepared → clipboardWritten → dispatched / copiedOnly / unknown | 不确定不自动重试，避免重复插入 |
| 同步 | localPending → uploading → acknowledged 或 conflict/retryableFailure | 退避重试只针对幂等变更，账号错误等待用户 |
| 外部写操作 | pendingApproval → approved → committing → committed / rejected / failed / unknown | 提交前再验权；按 operationID 查询结果 |
| 删除 | pendingUndo → committedLocal → pendingRemote → acknowledged | 立即删除跳过撤销；正文回收不等于远端已清除 |

统一错误码包括 CAPTURE_SKIPPED、UNSUPPORTED_TYPE、LIMIT_EXCEEDED、STORAGE_FULL、PERMISSION_REQUIRED、TARGET_CHANGED、ASSET_UNAVAILABLE、ACCOUNT_CHANGED、SYNC_QUOTA、REVISION_CONFLICT、ACCESS_REVOKED、MODEL_UNAVAILABLE、APPROVAL_REQUIRED、RESULT_UNKNOWN、MIGRATION_FAILED。错误显示面向用户的中文/英文说明及恢复动作，底层日志不得携带正文。

## 6. 非功能验收目标

以下是目标值，尚未测量。T01 登记真实测试设备/系统；不允许为了通过而换成更小数据集或隐藏失败。

| 指标 | 条件与目标 |
|---|---|
| 快捷面板 | Apple Silicon 8 GiB 及以上参考 Mac，10 万条元数据，20 次热唤起 P95 ≤ 150 ms |
| 搜索 | 同设备，10 万条每条约 0.5 KiB 文本，索引就绪；20 个中英查询首屏 P95 ≤ 200 ms |
| 小文本采集 | 同设备，前台普通负载，连续 100 次每次间隔 500 ms；已观测项从检测到持久化 P95 ≤ 300 ms，缺失需定位并列出 |
| 主进程 | 空闲 5 分钟，无 OCR/同步/模型任务；平均 CPU < 1%（单核口径），RSS 目标 ≤ 150 MiB |
| 键盘扩展 | 参考真机最近 1000 条轻量索引，冷打开 P95 ≤ 500 ms，峰值内存目标 ≤ 40 MiB；同时要求系统无异常终止，数字不是系统保活保证 |
| 活跃同步 | 双方在线、应用前台、正常 iCloud 的 30 次小文本样本，P95 目标 ≤ 10 秒；后台时延只报告不承诺 SLA |
| 推荐质量 | 在模型支持的中英文设备配置上，各 15 个预先标注上下文，共 30 例；正确项进入前 3 的比例 ≥ 80%，且不得返回无权限/不存在项；不足时继续改进而非仅以 API 可调用通过 |
| 完整性 | 故障注入后无悬空已完成记录；导出导入哈希/数量/收藏关系一致；删除与撤权不能被旧变更复活 |
| 稳定性 | Mac 24 小时合成数据运行、休眠唤醒；移动扩展反复切换 200 次，无不可恢复数据丢失 |
| 存储 | 常规测试用合成文本/小图，单轮增量预算 ≤ 100 MiB；大数据性能测试先测空间且流式生成，用后只清理该轮数据 |

Intel/最低系统单独测量，不把 Apple Silicon 指标当作 Intel 已通过。耗能、键盘内存与 AI 延迟须记录分位数和测试上下文。

## 7. 明确差距与非目标

- 暂不做 Windows/Android、完整键盘输入法、动态模板语言、任意脚本执行、嵌套多标签系统、任意 PDF OCR、自建跨平台同步服务。
- 专有剪贴板格式仅承诺适配清单；不自动声称兼容所有设计工具。T02 必须给出真实覆盖表。
- F53 的系统级防捕获、Paste 专用导入、Intel 真机、Apple Intelligence 地区可用性均有独立验证门槛。失败不是删除任务的理由；差距未关闭时不得宣称对应能力等价。
- 业务定价、外部渠道合同和公开发布不由这份规格自动授权执行；它们不影响在本地完成全部产品实现和验证材料。

## 8. 技术核查来源（2026-10-15）

这些来源只支持平台约束，不证明 Copy 已实现。SDK 接口、部署目标和当前协议版本在实施时再验证，尤其不依赖网页中标为 Beta 的符号。
